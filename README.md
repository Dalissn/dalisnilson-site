# dalisnilson.com

Personal site built with Quarto and hosted on GitHub Pages.

## Pages

- `index.qmd`: home page and short bio
- `cv.qmd`: CV in HTML (this is what the business card QR code opens)
- `files/Dalis_Nilson_CV.pdf`: downloadable PDF

## Updating the CV

1. Edit `cv.qmd`.
2. Replace `files/Dalis_Nilson_CV.pdf` with the new PDF. Keep the same file name so existing links keep working.
3. Commit and push. GitHub rebuilds the site in about two minutes.

## Preview locally (optional)

Install Quarto from quarto.org, then run `quarto preview` in this folder.
